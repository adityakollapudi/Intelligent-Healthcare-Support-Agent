# Synthetic Virtual Care FAQ

> SYNTHETIC DEMONSTRATION DOCUMENT. This FAQ deliberately disagrees with the Synthetic Virtual Care Policy Summary so the prototype can demonstrate conflict handling.

## Virtual visit cost
Virtual primary care visits through the synthetic telehealth service have a $0 copay for members of all synthetic plans.

## How to start a virtual visit
Members start a virtual visit from the member portal under Care > Virtual visits. A video connection and a phone number are required.

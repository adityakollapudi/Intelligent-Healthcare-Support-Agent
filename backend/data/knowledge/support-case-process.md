# Synthetic Support Case Process

> SYNTHETIC DEMONSTRATION DOCUMENT. Describes how support cases work in the IHSA prototype.

## When to open a support case
Open a support case when the assistant cannot answer a question, when information appears to conflict, when a document needs a person to review it, or when you want to talk to a person.

## What happens after a case is created
Every case receives a case number in the format CASE-YYYY-NNNNNN. A new case starts with the status Open. A support agent assigns the case and changes its status to In progress. The agent may set the status to Awaiting user when more information is needed from you.

## Response times
Support agents aim to make first contact within 2 business days of case creation. These are prototype targets, not guarantees.

## Closing a case
When the agent provides a resolution, the case becomes Resolved. You can reopen a resolved case within 14 days. After that the case is closed.
